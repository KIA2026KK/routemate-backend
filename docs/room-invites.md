# 초대 코드와 통화방 이동

방 생성·내 방·검색 응답의 `inviteCode`는 새 방의 경우 읽기 쉬운 영문·숫자 8자리다.
V7 이전 방은 UUID에서 하이픈을 제거한 32자리 코드를 부여하며 기존 UUID 참여도 유지한다.
코드는 방 초대용이며 bearer 계정 인증·활성 운행·차량 출처 검증을 대체하지 않는다.

`POST /api/v1/rooms/join`

```json
{"code":"ABCDEFG2","replaceCurrent":false}
```

공백·영문 소문자는 정규화한다. 비공개 방도 유효 코드로 참여할 수 있으며 정원과 한 계정 한 방 제한은 동일하다.
종료·만료·다른 차량 출처의 코드는 `404 ROOM_UNAVAILABLE`, 만석은 `409 ROOM_FULL`이다.
현재 참가 방과 같은 코드로 재요청해도 인원을 늘리지 않는다.

다른 방으로 이동하려면 사용자 확인 후 `replaceCurrent:true`를 사용한다.
UUID를 이미 아는 검색 결과에서는 `POST /api/v1/rooms/{id}/switch`를 사용한다.
목표 방의 존재·출처·정원을 확인한 뒤 이전 방 퇴장과 새 방 참여를 한 트랜잭션으로 처리한다.
코드 오류·만석·존재하지 않는 방으로 이동에 실패해도 기존 참가 상태를 잃지 않는다.
성공 시 빈 이전 방은 닫으며 동시에 두 개의 활성 참가를 만들지 않는다.

검증: 비공개 코드 참여, 반복 참여, 만석, 출처 격리, 인증, 형식, 종료된 코드,
이전 32자리 코드 호환, 이동 실패 시 기존 참가 유지, 성공 시 활성 참가 한 건을 PostGIS 통합 시험으로 확인한다.
